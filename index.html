THE IDEA

The internet already has the opportunities. The problem is the noise.

Radar collects public opportunity feeds, normalises them, removes obvious duplicates and presents the useful bits in one place. The publishing layer is designed to run automatically through GitHub Actions, so the product can keep refreshing without a daily manual routine.
