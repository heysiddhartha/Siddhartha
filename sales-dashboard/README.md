# Website Sales Dashboard

Simple dashboard for Siddhartha's international website-sales prospecting system.

## Flow
Find → Qualify → Contact → Interested → Won

## Target markets
US, UK, Canada, Australia, Germany, UAE, Singapore, Netherlands, Ireland, New Zealand, Switzerland, Saudi Arabia.

## Cost target
₹0.

The dashboard is a simple static page. Current lead data is a verified snapshot; it is not automatically synced to the scheduled ChatGPT task because no external CRM/email database is connected.

Open `index.html` locally or through a GitHub Pages deployment if enabled for this repository.
